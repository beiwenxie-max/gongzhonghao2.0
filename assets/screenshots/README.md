# 📸 截图说明

这个目录用于存放产品演示截图。请在上传到 GitHub 前，将以下截图放入此目录：

## 必需截图

### 入门版
- `starter-preview.png` - 入门版基础模板效果展示（红白色系、石墨极简、摸鱼绿等）

### 进阶版
- `pro-ai-layout.png` - AI 智能排版效果展示
- `pro-gzh-design-skill.png` - gzh-design-skill 工具界面截图

### 专业版
- `enterprise-workflow.png` - 自动化流水线工作流示意图
- `enterprise-aiwrite-ui.png` - AIWriteX 网页界面截图
- `enterprise-article-preview.png` - 自动生成的文章预览效果

### 启动菜单（可选，如果不公开 U 盘脚本可省略）
- `enterprise-windows-menu.png` - Windows 启动菜单界面
- `enterprise-mac-menu.png` - Mac 启动菜单界面

## 截图要求

- 格式：PNG
- 尺寸：建议 1920x1080 或更高
- 内容：清晰展示功能界面，可适当打码敏感信息
- 命名：使用小写字母和连字符，如 `starter-red-white.png`

## 如何替换 README 中的图片链接

当前 README 中使用的是占位链接，上传截图后无需修改，GitHub 会自动渲染。

如果截图文件名不同，请更新对应 README 中的图片路径：
```markdown
![描述](../../assets/screenshots/你的截图文件名.png)
```
