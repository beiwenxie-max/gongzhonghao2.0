## 💻 技术相关

### Q: 我是小白，能用得来吗？

**入门版/进阶版：** 只需要会用浏览器和复制粘贴，零基础可用。

**专业版：**
- U 盘版：插上电脑双击启动，有菜单式操作，零基础可用
- 网盘版：需要自行安装 Python 和 Node.js，有一定技术门槛

### Q: 支持 Mac 和 Windows 吗？

三个版本都支持：
- **入门版/进阶版**：HTML 文件，任何系统都能打开
- **专业版 U 盘版**：同时包含 Windows (.bat) 和 Mac (.command) 启动脚本

### Q: 专业版需要联网吗？

- **第一次启动**：需要联网激活 AI 模型
- **日常使用**：
  - AIWriteX 写作需要联网（调用 AI API）
  - wechat-publisher 发布需要联网（调用微信 API）
  - md2oa 转换可以完全离线

### Q: 我的电脑配置要求高吗？

**入门版/进阶版：** 只要能打开浏览器就行，无配置要求。

**专业版：**
- CPU：任意双核处理器
- 内存：4GB 以上
- 硬盘：至少 2GB 可用空间
- 系统：Windows 7+ / macOS 10.13+

基本上 2015 年后的电脑都能流畅运行。

## 🔧 使用问题

### Q: 模板怎么用？

1. 用浏览器打开 `.html` 文件
2. 全选（Ctrl+A / Cmd+A）
3. 复制（Ctrl+C / Cmd+C）
4. 登录公众号后台，新建图文
5. 粘贴到编辑器（Ctrl+V / Cmd+V）
6. 替换成你自己的文字

### Q: AIWriteX 怎么配置公众号？

1. 启动 AIWriteX
2. 首次使用会弹出配置向导
3. 填入 AppID 和 AppSecret（从公众号后台获取）
4. 添加 IP 白名单（教程里有详细说明）
5. 保存后即可使用

详细步骤见专业版教程文档。

### Q: 生成的文章可以直接发布吗？

AI 生成的文章会先推送到公众号的**草稿箱**，你需要：
1. 登录公众号后台
2. 打开草稿箱
3. 预览检查（建议通读一遍，微调个别措辞）
4. 点击"发布"

微信不允许第三方工具直接发布，这是平台限制，所有自动化工具都一样。

### Q: AI 写的文章质量怎么样？

AIWriteX 基于 CrewAI 多 Agent 架构，配合通义千问大模型，生成的文章：
- ✅ 逻辑清晰，结构完整
- ✅ 语言流畅，无明显语法错误
- ✅ 能结合热点素材，有一定深度
- ⚠️ 但可能需要人工微调：个别数据核实、语气调整、加入个人观点

**最佳实践：** 把 AI 当作"初稿助手"，你负责审核和点睛之笔。

## 📦 U 盘相关

### Q: U 盘容量多大？

建议 4GB 以上 U 盘，实际占用约 1.2GB：
- 工具源码：~200MB
- Python (Win+Mac)：~300MB
- Node.js (Win+Mac)：~200MB
- 预装依赖包：~500MB
- 教程文档：~10MB

剩余空间可以用来存你的文章素材、图片等。

### Q: U 盘是什么格式的？

格式化为 **exFAT**，同时支持 Windows 和 macOS 读写大文件。

### Q: U 盘坏了怎么办？

- **保修期内（30 天）**：免费更换新 U 盘
- **保修期外**：可付费购买新 U 盘（成本价 ¥20-30）

建议定期备份 U 盘内容到你的电脑或云盘。

### Q: 可以把 U 盘内容复制到电脑上用吗？

可以！U 盘里的所有内容都可以复制到电脑硬盘上使用。U 盘只是提供了一个"即插即用"的便利，核心功能不依赖 U 盘硬件。

## 🛡️ 安全与隐私

### Q: 我的公众号 API Key 安全吗？

API Key 只保存在你的本地配置文件（`user_config.json`）中，不会上传到任何服务器。U 盘版用户的配置文件存储在 U 盘里，离线使用，安全性更高。

**建议：**
- 不要将 `user_config.json` 分享给他人
- 定期更换 AppSecret（在公众号后台重置）
- U 盘妥善保管，避免丢失

### Q: AI 写作会泄露我的数据吗？

AIWriteX 调用的是阿里云通义千问 API，你的话题和内容会发送到阿里云进行处理。根据阿里云的隐私政策：
- 数据仅用于生成回复，不会被存储或用于训练
- 符合中国网络安全法规

如果你对数据安全有极高要求，建议在专业版中使用本地部署的开源模型（需要自行配置，技术门槛较高）。

### Q: 生成的文章有版权吗？

AI 生成的文章版权归**使用者**所有。你可以：
- 以自己的名义发布
- 进行商业变现
- 修改、二次创作

但请注意：
- 文章中引用的外部素材（图片、数据）可能涉及版权问题，建议核实来源
- 避免直接复制他人的原创内容
