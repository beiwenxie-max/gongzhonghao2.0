## ❓ 常见问题

### Q: 我是完全新手，应该选哪个版本？

**建议从入门版开始。** 先花 1 小时学习排版基础，套用 4 套模板写出几篇文章。当你觉得"每次手动排版好麻烦"时，再升级到进阶版或专业版。

### Q: 进阶版和专业版的 AI 工具有什么区别？

- **进阶版的 AI**：只负责**排版**。你写好文章，AI 帮你美化。
- **专业版的 AI**：负责**写作 + 排版 + 发布**。你只给一个话题，剩下的全自动。

### Q: 专业版的 U 盘真的插上就能用吗？

是的！U 盘里预装了 Python 3.12 和 Node.js 20，还有所有依赖包。插上电脑，双击启动脚本，就能看到菜单界面。第一次用需要联网激活 AI，之后可以完全离线使用。

### Q: 支持 Mac 和 Windows 吗？

三个版本都支持。入门版和进阶版的模板是 HTML 文件，任何电脑都能打开。专业版的 U 盘启动脚本同时支持 Windows (.bat) 和 macOS (.command)。

### Q: 买了之后有更新吗？

- **入门版**：一次性交付，无后续更新
- **进阶版**：每季度新增 2-3 套模板
- **专业版**：每月更新工具版本，每季度新增案例
